Site Settings

Configure the basic identity of your site. The site name is used in emails, page titles and system references.

Restricted Site Access

Use it on development, testing, staging or private sites. With restricted access enabled, every page requires sign in, public pages included, and the whole site is flagged so search engines do not index it (noindex, nofollow). Sign in screens, APIs, payment webhooks and static files keep working.

#site-restricted-profiles-badges#
Click the x on a profile to remove it. With an empty list, any signed in user has access. Your own profile must be in the list to save, so you do not lock yourself out of this screen.

Bots and Crawlers

The system already recognizes the most common bots with no configuration at all. Enable this option only if your site gets heavy traffic from a specific bot that is not in the list below yet.

Matching is done by User-Agent substring, case insensitive.
