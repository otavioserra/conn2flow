Acesso Restrito ao Site

Use em ambientes de desenvolvimento, testes, homologação ou sites privados. Com o acesso restrito ativo, todas as páginas passam a exigir login, inclusive as públicas, e o site inteiro é marcado para não ser indexado por buscadores (noindex, nofollow). As telas de login, as APIs, os webhooks de pagamento e os arquivos estáticos continuam funcionando.

#site-restricted-profiles-badges#
Clique no x de um perfil para removê-lo. Com a lista vazia, qualquer usuário logado tem acesso. O seu próprio perfil precisa estar na lista para salvar — assim você não se tranca para fora desta tela.

HTML entregue ao navegador

Remove do código-fonte das páginas os comentários de desenvolvimento e a indentação. Numa página real isso reduz cerca de um terço do arquivo, e evita que anotações internas sobre a estrutura do sistema fiquem visíveis para quem abre o código-fonte. O conteúdo exibido não muda.

O conteúdo de <pre>, <textarea> e <script> nunca é alterado, e os comentários condicionais são preservados.
A limpeza do JavaScript usa um leitor que reconhece strings, template literals e expressões regulares, então // dentro de uma URL ou de um texto não é confundido com comentário. Blocos <script> que guardam dados (application/json, text/template) nunca são processados. Esta chave existe separada para você poder desligar apenas esta parte diante de uma suspeita, sem devolver os comentários de HTML e CSS à página.

Robôs e Rastreadores

O sistema já reconhece os robôs mais comuns sem nenhuma configuração. Ative esta opção apenas se o seu site receber muito acesso de um robô específico que ainda não esteja na lista abaixo.

A comparação é por trecho do User-Agent, sem diferenciar maiúsculas de minúsculas.

Configurações de Usuário

Gerencie a segurança de autenticação dos usuários. Ative o reCAPTCHA para proteger formulários de login e cadastro contra bots e ataques automatizados.

Métodos de Login

Para configurar: Acesse o Google Cloud Console, crie um projeto, vá em "Tela de consentimento OAuth", depois em "Credenciais" -> "Criar credenciais" -> "ID do cliente OAuth" (Aplicativo Web). Adicione a URI de redirecionamento abaixo em "URIs de redirecionamento autorizadas".

Cadastre esta URI exatamente assim no Google Cloud Console.

Para configurar: Acesse o portal Meta for Developers, crie um aplicativo do tipo "Consumidor", adicione o produto "Login do Facebook", vá em "Configurações do Login do Facebook" e insira a URI de redirecionamento abaixo em "URIs de redirecionamento do OAuth válidas".

Cadastre esta URI exatamente assim no painel de Apps da Meta.
Permite que usuários se autentiquem informando o e-mail cadastrado e recebendo um código de acesso de 6 dígitos.
