Visual model

When you pick a model, its HTML and CSS go into the editor below. From then on what counts is the editor content, saved in this record.
Each section is a slide

In the editor, each <section data-slide> is a slide: copy a section to create another. Dots, arrows, counter, progress bar, keyboard, touch and printing come from the widget, according to the options above. To jump to a slide from inside the content, use data-c2f-deck-goto="0" on a button or link (counting starts at zero).

Slides

Each card is a slide of the deck. Drag by the or use the arrows to reorder; edit, duplicate or delete from the card. An image slide opens the file manager and accepts several images in a row. The content lives in the deck HTML: what you change here shows up in the editor and vice versa.
