Cada seção é um slide

No editor, cada <section data-slide> é um slide: copie uma seção para criar outro. Pontos, setas, contador, barra de progresso, teclado, toque e impressão saem do widget, conforme as opções acima. Para pular para um slide de dentro do conteúdo, use data-c2f-deck-goto="0" num botão ou link (a contagem começa em zero).

Slides

Cada cartão é um slide do deck. Arraste pelo ou use as setas para reordenar; edite, duplique ou exclua pelo cartão. Slide de imagem abre o gerenciador de arquivos e aceita várias imagens em sequência. O conteúdo fica no HTML do deck: o que você muda aqui aparece no editor e vice-versa.
