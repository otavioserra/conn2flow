# 2.10.0

Os modais de sistema viraram dependências automáticas das páginas Tailwind. Assets externos usados pelo painel passaram a ter cópias locais, e o build ganhou minificação de JS e CSS. Listagens administrativas em telas largas ganharam rolagem horizontal sem capturar a rolagem vertical da página. O tipo de campo de editor de texto foi padronizado como `editor-texto`. Veja [interface administrativa](../concepts/admin-interface.md).
