# 3.0.0

Todos os módulos administrativos saíram do Fomantic-UI para Tailwind CSS v4, com biblioteca de controles, diálogos próprios no lugar dos nativos do navegador e listagem com ordenação por várias colunas. O Dashboard ganhou a grade de módulos com capas, a área de widgets com layout por perfil e a lousa livre (texto, forma, imagem, ícone e botão), com lousas nomeadas, versões, o widget "Lousa" para qualquer página e o módulo "Páginas de Lousa". A linha 3.1 foi incorporada à 3.0 nesta versão.

A atualização do sistema passou a trabalhar com manifesto por camada, trava de deploy, backup, snapshot, verificação de saúde e volta automática. Os choques entre o arquivo entregue e o alterado no destino são resolvidos por arquivo no painel, na API e no CLI (`c2f update:conflicts`, `update:resolve` e `update:rollback`). O `c2f update:core` dispara a atualização pela API e a acompanha.

O core também ganhou página inicial e layout por perfil, a camada de provedores de IA (Gemini, Claude, OpenAI e compatíveis), o ponto de extensão das telas do painel, os módulos `presentations` e `cookie-consent`, a publicação da documentação (`c2f docs:audit`, `docs:extract` e `docs:build`) e o índice de idioma + caminho em `paginas`. Na segurança, a listagem ficou sem SQL injection, excluir e status passaram a exigir token CSRF, e página com `sem_permissao = 0` passou a exigir login.

> [!IMPORTANT]
> Quem vem da 2.10.x deve atualizar direto para a versão mais recente da série 3.0: as 3.0.1 e 3.0.2 corrigiram justamente a atualização a partir da 2.10.

Veja [atualizações do sistema](../concepts/system-updates.md), [choques](../reference/libraries/atualizacoes-choques.md) e [Dashboard](../reference/modules/dashboard.md).
