# 3.0.4

Em `admin-paginas` e `publisher-pages`, a página pode ser pública (padrão) ou acessível só pelo link direto privado (`?acesso=<hash>`). A página não visível sai do sitemap e dos widgets de índice e responde 404 para o visitante comum. O link válido libera a navegação na sessão, o administrador sempre vê a página e o link pode ser regenerado com um clique.

Com o acesso restrito do site ligado, o administrador pode autorizar o navegador atual em `admin-environment` para navegar pelas páginas públicas como visitante deslogado. O passe é um cookie HttpOnly assinado com HMAC-SHA256, com validade configurável. É possível revogar o navegador atual ou todos de uma vez (rotação do salt no `.env`).

Veja [páginas](../reference/modules/admin-paginas.md) e [ambiente](../reference/modules/admin-environment.md).
