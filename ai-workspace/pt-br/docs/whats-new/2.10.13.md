# 2.10.13

O core adicionou a rota `_gestor-csrf-token` para obter um token renovado. O JavaScript global identifica a resposta `CSRF_INVALID_OR_EXPIRED`, renova o token e repete a requisição nos caminhos `fetch`, `jQuery.ajax` e `XMLHttpRequest`. Ao voltar para uma aba visível, verifica o token de modo proativo. A resposta do endpoint e o retry seguem o contexto da sessão do usuário.
