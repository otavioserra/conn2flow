# CLI: Comandos tailwind

## `tailwind:fix-spacing`

Código: `cli/src/Commands/TailwindFixSpacingCommand.php`.

```text
Usage: c2f tailwind:fix-spacing [--target=../target-folder]

Normalizes arbitrary tailwind classes into canonical project tokens.
```
