# Documentação do Conn2Flow

O Conn2Flow é um framework PHP para construir sites e sistemas administrativos a partir de **recursos** (páginas, layouts, componentes, templates e variáveis) que vivem em arquivos versionados e são sincronizados para o banco. Esta documentação é mantida junto com o código, e cada página indica o commit contra o qual foi conferida.

## Por onde começar

- **Guias**: passo a passo para tarefas concretas. Comece por [Como escrever e publicar a documentação](guides/documentation.md).
- **Referência**: o que cada biblioteca e módulo faz, com o comportamento real.
  - [Biblioteca modelo.php](reference/libraries/modelo.md): templates, variáveis e blocos.
  - [Módulo menus](reference/modules/menus.md): menus de navegação por widget.
