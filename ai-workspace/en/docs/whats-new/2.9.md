# 2.9 series

The root `CHANGELOG.md` records the series beginning with 2.9.0. Version 2.9.39 added the contextual Live Editor toolbar on published pages, insertion and custom-code panels, session templates, backups, and AI assistance with CodeMirror. Version 2.9.51 expanded batch file selection, gallery density controls, and vertical image positioning. It also fixed MIME normalization, image validation, and empty-widget delivery in the editor.

These are historical release notes. For the current widget flow, see [Widgets](../concepts/widgets.md); for screen and preview CSS, see [CSS and Tailwind](../concepts/css-and-tailwind.md).
