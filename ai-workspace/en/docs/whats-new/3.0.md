# 3.0 series

## 3.0.14 to 3.0.9

3.0.14 republishes the changed files in `public_html/dist/` on every system update and every project deploy through the API. 3.0.13 cut the wait before a 404 on a missing URL from ~7.8 s to ~26 ms and made the conflict list refresh without reloading the tab. 3.0.12 removed false-positive conflicts on generated artifacts and added bulk decisions. 3.0.11 and 3.0.10 fixed deploys with many conflicts and the database step of the panel updater, which now keeps whatever would be retired until someone confirms. 3.0.9 brought the API CRUD engine for modules that declare `api.crud` and the portable Tailwind cache. See [3.0.14](3.0.14.md), [3.0.12](3.0.12.md), and [3.0.9](3.0.9.md).

## 3.0.8 to 3.0.4

These releases hardened the panel updater: the lock is released after an error (fatal ones included), a dead lock owner is detected without `/proc`, the database session gets a long `wait_timeout`, and the updater's own files are always delivered. SSH deploys write with the destination owner even when connecting as root. 3.0.4 added page visibility with a private direct link, and the trusted browser pass for sites with restricted access. See [3.0.4](3.0.4.md).

## 3.0.3 to 3.0.0

3.0.3 added the "Domain" form field. 3.0.2 and 3.0.1 fixed updates coming from 2.10.x and API deploys with the maintenance screen. 3.0.0 is the major release: the whole panel in Tailwind, a Dashboard with widgets and boards, and system updates with snapshot, health check, and automatic rollback. See [3.0.0](3.0.0.md), [system updates](../concepts/system-updates.md), and [admin interface](../concepts/admin-interface.md).
