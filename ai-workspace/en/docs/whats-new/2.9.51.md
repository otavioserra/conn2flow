# 2.9.51

The embedded file picker gained batch selection. Galleries gained density controls, quick editing for captions and links, and vertical image positioning. The release also adjusted image validation, MIME normalization in the administrative interface, and empty-widget delivery in the Live Editor. See [widgets](../concepts/widgets.md).
