# 2.10 series

## 2.10.13 and 2.10.12

Silent CSRF token renewal and automatic request retry cover `fetch`, jQuery AJAX, and `XMLHttpRequest`. The core added the `_gestor-csrf-token` endpoint. Version 2.10.12 added Cloudflare Turnstile, reCAPTCHA v3/v2 fallback in authentication screens, query-string preservation for 301 redirects, and automatic hook synchronization during project deployment.

## 2.10.11 through 2.10.8

The global XHR interceptor and restricted-site gate arrived in 2.10.11, along with fixes to SSH transport on Windows and access limits. Version 2.10.10 added independent execution for manually triggered cron tasks. Version 2.10.9 fixed template previews and pipeline transport. Versions 2.10.8 and 2.10.7 updated CI actions to Node 24.

## 2.10.6 through 2.10.0

The series removed redundant CI compilation, fixed checksum integrity across Windows and Linux, added template integrity tests, isolated styles in Tailwind previews, and introduced the cron module. Version 2.10.0 brought automatic system modal dependencies, local assets, minification, and responsive table changes. See [CSS and Tailwind](../concepts/css-and-tailwind.md) and [system updates](../concepts/system-updates.md).
