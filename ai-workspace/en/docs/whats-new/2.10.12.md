# 2.10.12

Cloudflare Turnstile became available in administrative settings, authentication screens, and the forms widget. Tailwind authentication gained a common reCAPTCHA v3/v2 and Turnstile flow, including fallback from v3 to v2. Redirects now preserve query strings, and forms-widget fragments remain within the widget. Project deployments now synchronize the [hooks](../concepts/hooks.md) table automatically; `project:sync-hooks` runs that stage alone.
