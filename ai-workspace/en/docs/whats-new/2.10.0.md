# 2.10.0

System modals became automatic dependencies of Tailwind pages. External assets used by the panel gained local copies, and the build added JS and CSS minification. Administrative listings on wide screens gained horizontal scrolling without capturing page vertical scrolling. The text-editor field type was standardized as `editor-texto`. See the [administrative interface](../concepts/admin-interface.md).
