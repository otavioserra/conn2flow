# 3.0.12

Artifacts generated by the installation itself (`vendor/`, `db/data/`, `*.min.js`, `*.precompiled.css`, asset manifests) and the core `config.php` now belong to their owning layer, so they no longer show up as manual conflicts. Line-ending-only differences (CRLF/LF) don't count. A conflict superseded by a later delivery resolves itself (`atualizacoes_choques_resolver_superados()`), and the screen gained pagination and bulk decisions, keep all or overwrite all, with confirmation (`atualizacoes_choques_resolver_lote()`). The `atualizacoes_choques` table moved to utf8mb4.

3.0.13 made pagination, filters, and decisions in the conflict list refresh without reloading the tab, and raised `wait_timeout` on the API deploy route. The other-language page lookup that runs before a 404 now uses the `(language, caminho)` index without reading HTML and CSS: from ~7.8 s to ~26 ms.

See [conflicts](../reference/libraries/atualizacoes-choques.md) and [updates](../reference/modules/admin-atualizacoes.md).
