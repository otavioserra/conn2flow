# 3.0.14

Up to 3.0.13, the JS and CSS served from `public_html/dist/` only changed after a manual `assets:publish`. After a release, browsers could keep getting the old script. Now every system update (CLI and panel) and every project deploy through the API call `instalacao_dist_ressincronizar()`, which compares the source files with the `dist/` manifest, rewrites what changed, and renews the `?v=` cache token.

> [!TIP]
> The result shows up in the deploy response under `installation.dist` (`verificados`, `atualizados`, `sem_fonte`, and `falhas`).

See [installation manifest](../reference/libraries/instalacao-manifesto.md).
