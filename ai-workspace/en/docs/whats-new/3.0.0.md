# 3.0.0

Every admin module moved from Fomantic-UI to Tailwind CSS v4, with a control library, built-in dialogs instead of the browser's native ones, and a list view that sorts by several columns. The Dashboard gained the module grid with covers, the widget area with per-profile layouts, and the free board (text, shape, image, icon, and button), with named boards, versions, the "Board" widget for any page, and the "Board Pages" module. The 3.1 line was merged into 3.0 in this release.

System updates now work with a per-layer manifest, deploy lock, backup, snapshot, health check, and automatic rollback. Conflicts between the delivered file and the one changed on the destination are resolved per file in the panel, the API, and the CLI (`c2f update:conflicts`, `update:resolve`, and `update:rollback`). `c2f update:core` triggers the update through the API and follows it.

The core also gained per-profile home page and layout, the AI provider layer (Gemini, Claude, OpenAI, and compatible), the panel screen extension point, the `presentations` and `cookie-consent` modules, documentation publishing (`c2f docs:audit`, `docs:extract`, and `docs:build`), and the language + path index on `paginas`. On security, the list view is free of SQL injection, delete and status require a CSRF token, and a page with `sem_permissao = 0` now requires login.

> [!IMPORTANT]
> Coming from 2.10.x, update straight to the latest 3.0 release: 3.0.1 and 3.0.2 fixed precisely the update from 2.10.

See [system updates](../concepts/system-updates.md), [conflicts](../reference/libraries/atualizacoes-choques.md), and [Dashboard](../reference/modules/dashboard.md).
