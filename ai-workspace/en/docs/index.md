# Conn2Flow documentation

Conn2Flow is a PHP framework for building websites and admin systems from **resources** (pages, layouts, components, templates and variables) that live in versioned files and are synchronized into the database. This documentation is maintained alongside the code, and every page states the commit it was checked against.

## Where to start

- **Guides**: step-by-step walkthroughs for concrete tasks. Start with [How to write and publish documentation](guides/documentation.md).
- **Reference**: what each library and module does, with its actual behavior.
  - [modelo.php library](reference/libraries/modelo.md): templates, variables and blocks.
  - [Menus module](reference/modules/menus.md): navigation menus through a widget.
