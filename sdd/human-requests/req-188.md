# Requisição 188 — Ajustes das Docs Online Após o Teste do Humano, Sitemap no Deploy e Exclusão de Páginas Órfãs

**Origem**: Humano, 2026-09-28, depois de testar o Lab (BATCH-190/191). Pontos relatados e pedidos no chat.
**Lote Vinculado**: `BATCH-192`.
**Status**: `approved` (Humano, 2026-09-28), implementada.

---

## Itens

1. **`whats-new` com 404** (`/en/docs/whats-new/2.10/`). Causa no roteador do core: `pathinfo('docs/whats-new/2.10/')` devolve a extensão `10`, e a requisição ia para o servidor de estáticos. `2.10.0/` escapava porque a extensão `"0"` é falsa no PHP. Correção: caminho terminado em barra nunca é arquivo.
2. **Menu: "Expandir tudo" e "Recolher tudo"** ao lado do filtro.
3. **SDD arquivado nas docs**: o `archive/` de cada pasta do SDD também deve aparecer. Publicado em `…/<pasta>/archive/<item>/`, num subgrupo "Arquivo" no fim da pasta, no menu.
4. **Esclarecimento** do teste manual sobre `gestor.md`/`libraries/index.md` (resposta no chat; sem código).
5. **Markdown cru no cabeçalho das páginas do SDD** (ex.: `1. **\`auth:cookie\` por SSH…**`). O resumo derivado do primeiro parágrafo era exibido sem renderização. Correção: resumo em texto puro, cortado numa palavra inteira.
6. **Sitemap no deploy** (pedido no chat, promove o [BL-019](../backlog/BL-019-sitemap-nao-atualizado-no-deploy.md) para a rota da API): `api_project_update()` regenera o `sitemap.xml` depois do banco e dos hooks, no contexto HTTP do site (que conhece o domínio). É o caminho do `project:deploy`.
7. **Exclusão das páginas órfãs das docs** (pedido no chat, parte do [BL-025](../backlog/BL-025-docs-removidas-seguem-publicadas.md)): as páginas do SDD que foram para `archive/` continuavam no banco sob a URL antiga. Excluídas pela lista `deletar` do `project_tables_config.json` do site. A rotina automática de exclusão fica para o Humano, num lote futuro.

## Critérios de aceite

1. `/docs/whats-new/2.10/`, `/en/docs/whats-new/2.9/` e as demais versões respondem 200.
2. Menu com os dois botões; clique abre ou fecha todos os grupos.
3. `/docs/sdd/<pasta>/archive/<item>/` publicado; subgrupo "Arquivo" no menu; links do SDD para itens arquivados resolvem.
4. Cabeçalho das páginas do SDD sem `**`, crases ou links crus.
5. `project:deploy` devolve `"sitemap": "updated"` e o `sitemap.xml` lista as páginas das docs com o domínio do site.
6. As URLs antigas dos itens arquivados deixam de existir (redirecionam para `/404`).
