# req-120: Migração Completa das Telas de Autenticação, Cadastro e Recuperação de Senha para Tailwind CSS

- **Status do intake**: ready-for-intake
- **Data**: 2026-08-17
- **Origem**: etapa final do programa de modernização do módulo `perfil-usuario` e eliminação do Fomantic-UI nas telas públicas
- **Classificação**: migração de framework CSS (Tailwind v4), refatoração de frontend, acessibilidade
- **Batch candidato**: BATCH-121

---

## 1. Contexto e Objetivos

O módulo `perfil-usuario` contém 15 páginas públicas e fluxos de autenticação além do painel de perfil. Atualmente, todas essas páginas dependem do CSS e dos padrões do Fomantic-UI (`.ui.form`, `.ui.segment`, `.ui.message`, `.ui.button`, etc.).

Esta requisição completa a migração do módulo `perfil-usuario`, reconstruindo todas as páginas de login, cadastro, recuperação de senha, step-up auth e fluxos OAuth em **Tailwind CSS v4** puro com componentes Vanilla JS leves, garantindo design moderno, responsividade perfeita, excelente tempo de carregamento e acessibilidade WCAG.

---

## 2. Inventário de Páginas e Escopo de Migração

Todas as páginas abaixo devem ser migradas em `gestor/modulos/perfil-usuario/resources/pt-br/pages/` e `resources/en/pages/`:

| Página / Rota | Descrição do Fluxo | Ações de Migração |
| :--- | :--- | :--- |
| **`acessar-sistema`** | Tela principal de login (Sign-in) | Card moderno centralizado com suporte a login por senha, código por e-mail (passwordless), botões de login social (Google, Meta) e links para cadastro/esqueci senha em Tailwind CSS. |
| **`cadastrar-no-sistema`** | Tela de cadastro público (Sign-up) | Formulário fluido com validação de força de senha em tempo real, termos de uso e integração com reCAPTCHA invisível/v3. |
| **`Area-restrita`** | Step-Up Auth / Reautenticação | Modal/Card elegante para reconfirmação de senha antes de operações críticas. |
| **`esqueceu-a-senha`** | Solicitação de reset de senha | Formulário limpo com validação de e-mail e envio de link de recuperação. |
| **`esqueceu-a-senha-email-enviado`** | Confirmação de disparo de e-mail | Tela informativa com ícone de sucesso e orientações claras de caixa de entrada/spam. |

## 3. Diretrizes de Implementação Técnica

1. **Substituição de Controles Fomantic-UI**:
   - Campos de formulário: `w-full rounded-lg border border-slate-300 px-3.5 py-2.5 text-slate-900 focus:border-emerald-600 focus:ring-2 focus:ring-emerald-600/20 transition`;
   - Mensagens de erro/sucesso: banners com ícones SVG / Lucide e cores semânticas (`bg-emerald-50 text-emerald-800 border-emerald-200` para sucesso, `bg-rose-50 text-rose-800 border-rose-200` para erro);
   - Botões principais e secundários em Tailwind com estados `:hover`, `:active`, `:focus-visible` e `:disabled`.
2. **Pré-compilação e Recursos**:
   - Declarar `framework_css = "tailwindcss"` em todos os metadados das páginas;
   - Gerar os arquivos `.precompiled.css` para cada uma das 15 páginas em `pt-br` e `en`.
3. **Preservação de Hooks e Parâmetros**:
   - Manter 100% dos nomes de campos POST, variáveis de template `@[[...]]@`, `#[...]#` e validações de CSRF existentes no backend `perfil-usuario.php`.

## 4. Critérios de Aceite e Validação

1. Todas as 15 páginas públicas do módulo `perfil-usuario` convertidas integralmente para Tailwind CSS em `pt-br` e `en`.
2. Zero dependências ou regras visuais quebradas do Fomantic-UI nessas páginas.
3. Fluxo completo de login $\to$ 2FA $\to$ logout $\to$ esqueci minha senha $\to$ redefinição testado e aprovado.
4. Testes automatizados Vitest e PHPUnit 100% verdes.
