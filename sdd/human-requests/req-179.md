## 1. Regras da migração

1. **Doc legada não é fonte, é pista.** Ela indica o assunto; o conteúdo novo sai do código. O que a doc legada afirma e o código não confirma é descartado.
2. **Ao migrar, o legado correspondente é apagado nos dois idiomas, no mesmo commit.** O histórico fica no git e na branch `legacy/ai-workspace-pre-docs`.
3. **Manual de usuário e doc técnica de um módulo viram uma doc só** (`reference/modules/<id>.md`), com uma seção "Como usar" e uma de referência técnica.
4. **Relatos de versão** (`-v2.6.3`, `-CONCLUIDO`, "Fase 1", "Correções implementadas") não são doc. O que for comportamento vigente entra na doc do assunto; o resto é descartado. O histórico de versões fica em `CHANGELOG.md`.
5. Informação sensível (hosts, IPs, caminhos de VPS, credenciais) nunca migra. Na dúvida, `visibility: restricted`.
