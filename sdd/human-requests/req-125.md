# Requisição 125 — Correção de Reload em Erro de CSRF/Sessão, Mapeamento de Ícones de Módulos de Projetos, Alternância de Botões Abrir/Fechar Menu e Eliminação de Warnings do Lucide

Esta especificação define os requisitos para:
1. **Recarregamento Limpo na Resposta de CSRF/Sessão Expirada (`gestor_csrf_resposta_invalida`):** Evitar que o botão "Voltar" recicle tokens CSRF expirados do cache do formulário de login (`signin/`), garantindo recarregamento forçado ou redirecionamento limpo;
2. **Mapeamento de Ícones para Módulos Adicionais / `conn2flow-site`:** Mapear pares de ícones Fomantic e Lucide para os módulos: Catálogo 3D (`catalogo-3d`, `catalogo-3d-grupos`, `catalogo-3d-itens`), Conexões Sociais (`conexoes-sociais`), Gateways de Pagamentos (`gateways-pagamentos`), Publicador de Mídias Sociais (`publicador-midias-sociais`), Social Apps (`social-apps`), Arquivos (`arquivos` / `admin-arquivos`) e Módulos Grupos Distribuídos;
3. **Alternância de Visibilidade dos Botões Abrir / Fechar Menu (`data-admin-abrir` e `data-admin-fechar`):** Garantir que apenas o botão contextual correspondente esteja visível de acordo com o estado do menu (menu aberto = botão fechar visível; menu fechado/colapsado = botão abrir visível);
4. **Eliminação de Warnings do Lucide no Console:** Saneamento de valores de `data-lucide` para não injetar nomes compostos legados do Fomantic (ex: `"comments outline"`, `"credit card outline"`), evitando poluição de logs no navegador.

---

## 1. Contexto e Motivação

1. **Loop de Sessão Expirada no Login:**
   - Ao falhar na validação CSRF (ou por sessão inativa/expirada), `gestor_csrf_resposta_invalida()` exibe a tela de erro com `<button onclick="history.back()">Voltar</button>`.
   - O comando `history.back()` restaura o estado do formulário em cache com o token CSRF expirado. Ao clicar em entrar novamente, a falha se repete em loop contínuo. É necessário forçar um reload limpo na tela de login (`/signin/`) ou navegar via `document.referrer` com geração de novos tokens.

2. **Ícones Ausentes em Módulos de Projetos:**
   - Módulos específicos consumidos por projetos derivados (`conn2flow-site` / `catalogo-3d`, `gateways-pagamentos`, `conexoes-sociais`, `publicador-midias-sociais`, `arquivos`, etc.) ainda não possuem pares válidos cadastrados no catálogo Lucide (`icone_tailwind`).

3. **Conflito Visual de Botões de Abrir/Fechar:**
   - No `layout-administrativo-tailwind`, tanto o botão `data-admin-abrir` quanto `data-admin-fechar` podem ficar visíveis simultaneamente no desktop, gerando confusão de interface.

4. **Warnings de Ícones no Console:**
   - A interpolação `<i data-lucide="#icon#" class="#icon# icon">` passa nomes compostos do Fomantic (ex: `comments outline`) diretamente para o Lucide, gerando mensagens de alerta `icon name was not found in the provided icons object` no console do navegador.

---

## 2. Escopo Técnico e Frentes de Implementação

### Frente 1: Recarregamento Limpo em `gestor_csrf_resposta_invalida()`
* **Arquivo:** `gestor/gestor.php`.
* **Solução:**
  - Atualizar o botão de retorno na tela de erro de CSRF para redirecionar ou recarregar:
    ```html
    <button type="button" onclick="if(document.referrer && document.referrer.indexOf('/signin') !== -1){ window.location.href = document.referrer; } else if(window.history.length > 1){ window.history.back(); } else { window.location.reload(); }">Voltar</button>
    ```
  - Quando a requisição de origem for a rota `signin/`, forçar o redirecionamento direto para a URL de login para garantir a emissão de novo token CSRF e cookie de sessão limpo.

### Frente 2: Cadastro de Ícones nos Módulos Adicionais
* **Arquivos:** Descritores `modulos/*.json`, banco de dados e migração.
* **Mapeamento de Pares Sugerido:**
  - `catalogo-3d`: Fomantic `cube`, Lucide `box`
  - `catalogo-3d-grupos`: Fomantic `cubes`, Lucide `boxes`
  - `catalogo-3d-itens`: Fomantic `cube`, Lucide `box`
  - `conexoes-sociais`: Fomantic `share alternate`, Lucide `share-2`
  - `gateways-pagamentos`: Fomantic `credit card outline`, Lucide `credit-card`
  - `publicador-midias-sociais`: Fomantic `bullhorn`, Lucide `megaphone`
  - `social-apps`: Fomantic `mobile alternate`, Lucide `smartphone`
  - `arquivos` / `admin-arquivos`: Fomantic `folder open outline`, Lucide `folder-open`
  - `modulos-grupos-distribuidos`: Fomantic `sitemap`, Lucide `network`

### Frente 3: Alternância de Visibilidade dos Botões de Abrir e Fechar Menu
* **Arquivos:** `layout-administrativo-tailwind.html` e `gestor/assets/global/admin-tailwind.js`.
* **Solução:**
  - Sincronizar as funções `abrir()` e `fechar()` no `admin-tailwind.js`:
    - Menu Aberto: `btnAbrir.classList.add('hidden')` e `btnFechar.classList.remove('hidden')`.
    - Menu Fechado/Recolhido: `btnAbrir.classList.remove('hidden')` e `btnFechar.classList.add('hidden')`.
  - Garantir o estado inicial correto no carregamento da página conforme o estado persistido (`localStorage`).

### Frente 4: Tratamento de Nomes de Ícones Lucide (Fim dos Warnings)
* **Arquivos:** `gestor.php` (`gestor_pagina_menu_icone`) e componentes de menu Tailwind.
* **Solução:**
  - Garantir que `data-lucide` só seja emitido quando o valor for um nome válido de ícone do catálogo Lucide (identificador simples em kebab-case, sem espaços como `"comments outline"`).
  - Se o módulo só tiver o nome Fomantic legado, omitir o atributo `data-lucide` ou passar string vazia, deixando a renderização para a classe `class="#icon# icon"`.
  - No `admin-tailwind.js`, o `desenharIcones()` processará exclusivamente os elementos com `data-lucide` preenchidos e válidos.

---

## 3. Critérios de Aceite

1. **Zero Loop no Login:** Clicar em "Voltar" após erro de sessão expirada recarrega a tela de login com novo token válido.
2. **Ícones Exibidos:** Módulos de Catálogo 3D, Gateways, Redes Sociais, Arquivos e Módulos Grupos Distribuídos exibem seus respectivos ícones no menu.
3. **Alternância de Botões de Menu:** No desktop e mobile, o botão "Abrir menu" só aparece quando o menu estiver colapsado; o botão "Fechar menu" só aparece quando o menu estiver expandido.
4. **Console Limpo:** Zero warnings de `icon name was not found` emitidos pelo Lucide ao carregar o painel administrativo.
5. **Testes:** `composer test` (PHPUnit), `npm run test` (Vitest) e `php -l` 100% verdes.
