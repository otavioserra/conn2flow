# Requisição 212 — Modal de edição do editor visual sem estilo no documento Tailwind

**Origem**: relato do Engenheiro Chefe Humano no chat, em 2026-10-02 ("no editor visual... está com alguns problemas de CSS... por exemplo `html-editor-modal`... dá uma revisada na biblioteca editor HTML para ver se esses elementos gráficos ficaram com algum resíduo de CSS sem aplicação").
**Lote Vinculado**: `BATCH-220` (`conn2flow` core).
**Status**: `in-review`.
**Modo**: `autonomo_monitorado`.

---

## 1. Pedido

1. Corrigir o modal "Editar elemento" do editor visual, que aparecia sem espaçamento nem borda.
2. Revisar os demais elementos gráficos do editor HTML atrás do mesmo tipo de resíduo.

## 2. Critérios de aceite

1. No editor visual de uma página Tailwind, o modal abre íntegro nos três modos: texto, código e imagem.
2. O seletor de arquivos do campo de imagem abre e devolve a escolha.
3. A página dentro do editor continua igual à publicada: nenhuma folha de framework do painel rege o conteúdo.
4. Página com framework Fomantic não muda.
