# Requisição 126 — Mapeamento Completo de Ícones Tailwind/Lucide para os Módulos Restantes do Projeto `conn2flow-site`

Esta especificação define os requisitos para cadastrar os pares de ícones Tailwind/Lucide (`icone_tailwind`) nos 6 módulos restantes do projeto `conn2flow-site` (`pro-manager`, `pedidos`, `produtos`, `checkout`, `host-manager`, `host-user-manager`), atualizando os descritores JSON, o `ModulosData.json` e a migração de banco correspondente.

---

## 1. Contexto e Motivação

No lote `BATCH-127`, os primeiros 9 módulos do `conn2flow-site` receberam o mapeamento de ícones Lucide. Contudo, 6 módulos do catálogo de projetos ainda estavam sem a declaração `icone_tailwind`:
1. `pro-manager` (Pro Gerenciamento)
2. `pedidos` (Pedidos / Orders)
3. `produtos` (Produtos / Products)
4. `checkout` (Checkout)
5. `host-manager` (Host Manager)
6. `host-user-manager` (Minha Hospedagem / My Hosting)

Para garantir paridade total entre os layouts Fomantic e Tailwind, esses módulos precisam ter seus ícones declarados nos descritores JSON de módulos, no `ModulosData.json` do `conn2flow-site` e na migração Phinx para atualização de bancos existentes.

---

## 2. Escopo Técnico

### Mapeamento de Pares (`icone` Fomantic ➔ `icone_tailwind` Lucide):
| Módulo ID | Nome (`pt-br` / `en`) | `icone` (Fomantic) | `icone_tailwind` (Lucide) |
| :--- | :--- | :--- | :--- |
| `pro-manager` | Pro Gerenciamento / Pro Management | `clipboard check` | `clipboard-check` |
| `pedidos` | Pedidos / Orders | `receipt` | `receipt` |
| `produtos` | Produtos / Products | `box` | `package` |
| `checkout` | Checkout | `shopping cart` | `shopping-cart` |
| `host-manager` | Host Manager | `server` | `server` |
| `host-user-manager` | Minha Hospedagem / My Hosting | `cloud` | `cloud` |

### Arquivos Alvo:
1. **`conn2flow-site/gestor/db/data/ModulosData.json`**: Adicionar `"icone_tailwind"` nos registros `pt-br` e `en` dos 6 módulos.
2. **Descritores de Módulos em `conn2flow-site/gestor/modulos/`**:
   - `pro-manager/pro-manager.json`
   - `pedidos/pedidos.json`
   - `produtos/produtos.json`
   - `checkout/checkout.json`
   - `host-manager/host-manager.json`
   - `host-user-manager/host-user-manager.json`
3. **Migração no Core (`conn2flow/gestor/db/migrations/`)**:
   - Atualizar/expandir a migração de update de ícones dos módulos de projetos para contemplar esses 6 módulos com `icone_tailwind`.

---

## 3. Critérios de Aceite

1. **Catálogo Completo:** Todos os 15 módulos do `conn2flow-site` possuem pares válidos de `icone` e `icone_tailwind`.
2. **Migração Segura:** A execução de `phinx migrate` atualiza as colunas `icone_tailwind` no banco de dados para todos os 6 módulos sem erros ou dependência de ordem.
3. **Validação:** Suíte PHPUnit e Vitest sem regressões.
