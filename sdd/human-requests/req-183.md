## 3. Regras de convivência (obrigatórias)

1. **Só edite** `ai-workspace/{pt-br,en}/docs/concepts/` (os quatro conceitos da onda 1 só para correção de link), `whats-new/`, os legados da tabela §2 e `sdd/implementation/BATCH-187.md`. Os índices (`BATCH-INDEX.md`, `CURRENT.md`, `VALIDATION-CHECKLIST.md`) são do agente da req-179.
2. **Não rode** `c2f docs:build`, `project:update-all`, `css:rebuild` nem `resources:sync`: o pipeline é exclusivo do agente da req-184. `docs:audit` e `docs:extract` podem ser rodados.
3. **Git:** `git fetch` e `git rev-list --count HEAD..origin/main` antes de cada push (se houver commits novos, `git pull --rebase` só com a sua árvore limpa); `git add` só com os seus caminhos (nunca `-A` nem `.`); commits pequenos com `docs(core): <escopo> (BATCH-187 / req-183)` e a linha `Co-Authored-By`; push após cada commit.
4. **Heredoc do Git Bash corrompe barras invertidas e aspas.** Use as ferramentas de arquivo (Write/Edit) ou um script salvo em arquivo.
5. **Links** só para `.md` existentes; link quebrado aborta o build. A limpeza final não pode deixar link apontando para arquivo apagado.
6. **Conteúdo público:** sem hosts, IPs, credenciais ou caminhos de servidor reais.
