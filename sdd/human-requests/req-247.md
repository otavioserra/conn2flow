## 2. Escopo

### 2.1 Permissões (duas operações do módulo `dashboard`)

| Operação | Quem tem | O que pode |
|---|---|---|
| `widgets-administrar` | perfil `administradores` na instalação; os demais recebem pelo `usuarios-perfis` | editar a área de widgets, manter layout próprio, salvar layouts e definir o layout de cada perfil |
| `widgets-visualizar` | concedida por perfil | ver a área de widgets com o layout definido para o perfil, sem nenhum controle de edição |

Sem nenhuma das duas, a aba de widgets não aparece. A regra vale no servidor: gravar layout, salvar e publicar exigem `widgets-administrar`; renderizar widget exige uma das duas.

### 2.2 Layout por perfil

- Quem administra publica o layout que está na tela para um ou mais perfis, ou para todos (`*`). Um perfil sem layout próprio usa o de todos.
- Quem só visualiza vê o layout do perfil.
- Quem administra escolhe o que vê: o próprio layout ou o padrão do perfil. No padrão, o modo de edição fica desligado e há a ação de copiar o padrão para o próprio.

### 2.3 Layouts salvos

Quem administra guarda o arranjo atual com um nome, aplica um guardado ao próprio layout e exclui. Ficam na preferência do usuário.

### 2.4 Ferramentas do card e do menu

- **Duplicar widget**: copia o card com tipo, registro, tamanho e configurações.
- **Abrir o registro para editar**: atalho do card para a tela de edição do registro, em nova aba, quando o módulo do widget tem essa tela e o usuário tem acesso a ele.
- **Larguras**: de 2 a 12 colunas da malha de 12, uma a uma, no lugar dos quatro degraus (4, 6, 8, 12). Altura inalterada.
- **Menu de opções**: mostrar ou esconder todos os cabeçalhos de uma vez; tela cheia da área de widgets.

## 3. Critérios de aceite

- [ ] Usuário só com `widgets-visualizar`: vê os widgets do perfil, sem modo de edição, sem botões de card, sem itens de edição no menu; tentativas de gravar pelo AJAX são recusadas.
- [ ] Usuário com `widgets-administrar`: publica layout para um perfil e para todos, alterna entre próprio e padrão, copia o padrão.
- [ ] Layouts salvos: salvar, aplicar e excluir persistem depois de recarregar.
- [ ] Duplicar gera card independente; abrir registro leva à edição certa.
- [ ] Redimensionar aceita todas as larguras de 2 a 12 colunas; layouts antigos continuam válidos.
- [ ] Mostrar/esconder todos os cabeçalhos e tela cheia funcionam.
- [ ] PHPUnit e Vitest verdes; roteiro de navegador no Lab com um usuário de cada tipo; 390 px sem rolagem lateral.
- [ ] Textos novos no sistema de variáveis, nos dois idiomas.
