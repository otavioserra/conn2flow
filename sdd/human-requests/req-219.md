# req-219 — Painel em Tailwind: biblioteca de controles e migração do `admin-paginas`

- **Status:** `in-progress`
- **Modo de Autonomia:** `autonomo_monitorado`
- **Lote Alvo:** `BATCH-227` (primeira fatia do programa)
- **Data de Criação:** 2026-10-03
- **Origem:** Engenheiro Chefe Humano no chat, promovendo o backlog: "evolução dos módulos todos para Tailwind; analisar todos os controles em Fomantic UI e passar para Tailwind; começar pelo `admin-paginas` e o editor HTML; construir os controles que faltam (select...); trocar os `alert` escritos à mão no JavaScript por um sistema com a estrutura do nosso modal; pode criar uma biblioteca de controles, com ou sem AJAX".
- **Backlog promovido:** BL-012 (substituição integral do Fomantic no painel, linha 3.0) e BL-026 (listagem do `interface` em Tailwind).

## Diagnóstico (2026-10-03)

- O layout Tailwind do painel carrega jQuery, mas não o JavaScript do Fomantic. O editor HTML (`html-editor*.js`, cerca de 10 mil linhas) chama `dropdown` 52 vezes, `modal` 36, `checkbox` 21, `tab` 11, `dimmer` 8, `popup` 5 e `search` 1. Por isso o `admin-paginas`, que tem o editor, continua no layout Fomantic.
- A API usada é pequena: `dropdown` (opções com `onChange`, `get value`, `set selected`, `refresh`), `checkbox` (marcar, ler, `onChange`), `tab`, `modal` (`show`, `hide`, `onApprove`, `onDeny`), `dimmer`, `popup`.
- Há 14 `alert`, `confirm` e `prompt` nativos no editor.
- Formulários, botões e modais do `interface` já têm variante Tailwind (req-190); a listagem não (BL-026).

## Programa (fatias)

1. **Biblioteca de controles** (`gestor/assets/interface/controles.js` e `.css`, sem framework): select com busca, múltiplo e opções por AJAX; chave liga/desliga; abas; diálogos (`alerta`, `confirmar`, `perguntar`, com Promise) na estrutura do modal do painel; avisos rápidos; dica; carregando. Ponte de compatibilidade: onde o Fomantic não está carregado, `$.fn.dropdown`, `checkbox`, `tab`, `modal`, `dimmer` e `popup` passam a usar os controles, com a mesma API usada no core. Ajudantes PHP em `gestor/bibliotecas/controles.php`.
2. **Diálogos no lugar dos nativos**: `alert`, `confirm` e `prompt` do editor e do `admin-paginas` passam para a biblioteca.
3. **`admin-paginas` em Tailwind**: incluir, editar e clonar no layout Tailwind, com os controles; o editor HTML funcionando sem o Fomantic.
4. **Editor HTML em Tailwind**: variantes Tailwind dos componentes do editor.
5. **Listagem em Tailwind** (BL-026).
6. **Demais módulos**, um lote por grupo.

## Critérios de aceite da primeira fatia

- CA-1: cada controle funciona sem Fomantic, com teclado e no celular (select com busca, múltiplo e AJAX; chave; abas; diálogos; avisos).
- CA-2: no layout Fomantic, nada muda (a ponte só entra sem o Fomantic).
- CA-3: nenhum `alert`, `confirm` ou `prompt` nativo no editor e no `admin-paginas`.
- CA-4: `admin-paginas` (incluir, editar, clonar) no layout Tailwind, sem o JavaScript nem o CSS do Fomantic, com o editor HTML gravando.
- CA-5: testes do core e roteiro de navegador.
