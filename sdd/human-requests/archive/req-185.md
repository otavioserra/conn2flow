## 1. Os ajustes pedidos

1. **Menu lateral centralizado no item atual.** Hoje, ao abrir uma página (ex.: Módulos → Usuários), o menu começa com a rolagem em 0 e o item atual pode ficar fora da tela. Ao carregar, depois de abrir o grupo da página atual, role o contêiner do menu (`[data-docs-scroll]` no `docs-article`) para que o link com `aria-current="page"` fique **centralizado na vertical**. Sem animação na carga; não role a página inteira, só o contêiner.
2. **Anterior/próximo com o rótulo do menu.** Os cartões de navegação no fim do artigo ainda mostram o título longo ("Biblioteca sitemap.php", "Biblioteca plugins.php"). Devem mostrar o mesmo rótulo do menu lateral: o nome do módulo (tabela `modulos`) para docs com `module:`, senão o `label:` do frontmatter, senão o título. Há um método para isso no builder (`menuLabel()`); use-o em `navHtml()`.
3. **Descrição das funções no bloco "Funções".** O bloco gerado pelo `c2f docs:extract` mostra assinatura e link para a linha. Acrescente, por função:
   - **o que ela faz**: o resumo do docblock (primeira frase ou primeiro parágrafo);
   - **o que cada parâmetro representa**: a descrição de cada `@param`, inclusive as chaves documentadas como `@param tipo $params['chave'] descrição` (hoje ignoradas para o tipo, com razão);
   - **o que devolve**: a descrição do `@return`.

   O formato é livre, mas legível no site e no Markdown (por exemplo, a assinatura como hoje e, abaixo, o resumo e uma sublista de parâmetros). Função sem docblock fica só com a assinatura. Depois, regenere os blocos com `php cli/c2f.php docs:extract --all` (só reescreve o bloco entre `<!-- c2f:extract:start/end -->`; o texto das docs não pode mudar) e confira com `docs:extract --all --check`.
4. **Remover "Editar esta página no GitHub".** Tire o link do rodapé de verificação (`verificationHtml()`) e a chave `edit` de `docs.config.json`. O selo "Verificado contra o código no commit …" e a lista de fontes continuam.
