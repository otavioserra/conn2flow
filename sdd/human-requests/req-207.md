# Requisição 207 — Docs: referência de funções em cartões e atualização do que mudou na req-206

**Origem**: pedido do Engenheiro Chefe Humano no chat, em 2026-10-02 ("na parte de funções… ficou uma listinha… dá uma característica visual melhor e uma navegabilidade melhor").

## 1. Pedido

Nas páginas de biblioteca da documentação publicada no site, a seção "Funções" é o bloco gerado pelo `docs:extract` passado pelo Markdown: uma lista corrida, com "linha 39" como link solto. Melhorar o visual e a navegação. Aproveitar para revisar as docs e incluir o que mudou.

## 2. Escopo

1. No `docs:build`, transformar o bloco de funções em filtro, índice e um cartão por função. O Markdown das docs não muda: continua sendo a forma lida no GitHub e no editor.
2. Regerar os blocos desatualizados (`docs:extract --all`).
3. Atualizar as docs que descrevem o que a req-206 mudou: retirada e reativação, `insert_only`, sementes de sistema num projeto, escrita que falha, conferência depois do deploy.
4. README: Conn2Flow Dev Tools na seção Ecossistema e instalação pelo último lançamento.

## 3. Critérios de aceite

1. Cada função tem âncora própria, assinatura copiável, parâmetros com tipo e link para a linha no repositório.
2. O filtro reduz cartões e índice; sem JavaScript, índice e cartões continuam funcionando.
3. Nenhuma função some na conversão: o número de cartões é o número de funções do bloco.
4. `docs:audit` sem erro; testes das docs passam.
