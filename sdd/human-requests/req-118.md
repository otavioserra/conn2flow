# req-118: Modernização do Painel de Perfil do Usuário em Tailwind CSS, Estrutura em Abas e Gestão de Sessões Ativas

- **Status do intake**: ready-for-intake
- **Data**: 2026-08-17
- **Origem**: solicitação do usuário para migração completa do módulo `perfil-usuario` de Fomantic-UI para Tailwind CSS e individualização de opções de segurança por usuário
- **Classificação**: modernização de UI/UX, segurança de autenticação, migração de framework CSS (Tailwind v4)
- **Batch candidato**: BATCH-119

---

## 1. Contexto e Objetivos

O módulo `perfil-usuario` gerencia a identidade, credenciais e segurança do usuário autenticado no Gestor/CMS. Atualmente, a interface utiliza o framework legado Fomantic-UI (`.ui.table`, `.ui.button`, etc.) e apresenta uma estrutura linear com links que abrem blocos isolados.

Esta requisição inicia o programa de modernização do módulo `perfil-usuario` com três grandes objetivos:
1. **Migração Integral para Tailwind CSS v4**: Eliminar todas as classes do Fomantic-UI no painel do perfil, utilizando classes utilitárias modernas e componentes interativos leves em JavaScript Vanilla para tabs, modais e mensagens;
2. **Estruturação em Abas/Navegação Moderna**: Organizar as configurações do usuário em abas temáticas e fluidas (Dados Cadastrais, Segurança & 2FA, Sessões Ativas & Dispositivos);
3. **Gestão de Sessões e Dispositivos Conectados**: Permitir que cada usuário visualize suas sessões ativas (IP, navegador, sistema operacional, data de login e última atividade) e tenha controle para revogar sessões individuais ou desconectar todos os outros dispositivos remotamente.

---

## 2. Escopo Técnico Requerido

### Módulo 1: Reestruturação da UI do Perfil em Abas com Tailwind CSS
* **Arquivos**:
  - `gestor/modulos/perfil-usuario/resources/pt-br/pages/perfil-usuario/perfil-usuario.html`
  - `gestor/modulos/perfil-usuario/resources/en/pages/perfil-usuario/perfil-usuario.html`
  - `gestor/modulos/perfil-usuario/perfil-usuario.js`
  - `gestor/modulos/perfil-usuario/perfil-usuario.php`
* **Implementação**:
  - Criar um sistema de Abas moderno em Tailwind CSS + JS:
    - **Tab 1: Dados Pessoais / Conta**: Nome completo (primeiro, meio, último), nome da conta, e-mail, nome de usuário, alteração de senha com medidor de força de senha em tempo real;
    - **Tab 2: Segurança & 2FA**:
      - Status atual da autenticação de dois fatores;
      - Ativação/desativação de TOTP via Aplicativo Autenticador (com renderização de QR Code e chave manual);
      - Ativação/desativação de 2FA por E-mail;
      - Gerenciamento de vínculos com Contas Sociais (Google, Meta);
    - **Tab 3: Sessões & Dispositivos**: Lista de acessos ativos e controle de revogação remota.
  - Manter a trava de **Área Restrita (Step-up Auth)** via `usuario_autorizacao_provisoria()` antes de efetivar alterações críticas de credenciais.

### Módulo 2: Gerenciamento de Sessões Ativas e Dispositivos
* **Biblioteca Core (`gestor/bibliotecas/usuario.php`)**:
  - Implementar as funções de auditoria e revogação de tokens:
    - `usuario_sessoes_listar(int $id_usuario, ?string $token_atual_pubID = null): array`: Consulta a tabela `usuarios_tokens`, parseia o `user_agent` (identificando navegador e sistema operacional) e marca a sessão que corresponde ao token atual;
    - `usuario_sessao_revogar(string $pubID, int $id_usuario): bool`: Remove o token específico da tabela `usuarios_tokens`;
    - `usuario_sessoes_revogar_outras(string $token_atual_pubID, int $id_usuario): bool`: Exclui todos os tokens do usuário exceto o token da sessão ativa.
* **Interface e Endpoints AJAX no `perfil-usuario`**:
  - Endpoint AJAX para revogar uma sessão específica por `pubID`;
  - Endpoint AJAX para "Desconectar de todos os outros dispositivos";
  - Exibição de cards de dispositivos com badges visuais (*"Este dispositivo"*, *"Chrome no Windows"*, *"Safari no iPhone"*, IP, data de acesso).

### Módulo 3: Pré-compilação e Contrato de Recursos
* Configurar `framework_css = "tailwindcss"` no `perfil-usuario.json` e nos metadados de recursos;
* Gerar os arquivos `.precompiled.css` para a página `perfil-usuario` em `pt-br` e `en`;
* Garantir paridade responsiva (mobile, tablet, desktop) sem quebra de layout.

---

## 3. Critérios de Aceite e Validação

1. A página `perfil-usuario` deve estar 100% livre de dependências visuais do Fomantic-UI, utilizando exclusivamente classes utilitárias do Tailwind CSS.
2. Navegação entre as abas (Dados Pessoais, Segurança & 2FA, Sessões Ativas) fluida e sem recarregamento de página via JavaScript nativo.
3. Lista de sessões ativas exibe com precisão a sessão atual e outras sessões do usuário com seus respectivos IPs e navegadores.
4. O botão "Revogar Sessão" remove o token do banco e derruba o acesso daquele dispositivo imediatamente.
5. O botão "Desconectar outros dispositivos" encerra todas as sessões exceto a atual com confirmação visual.
6. Testes unitários PHP (`composer test`) e testes de frontend Vitest (`npx vitest run`) 100% verdes.
