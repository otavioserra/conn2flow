# Memory Gardening SDD

1. Meça bytes e linhas da memória de execução e leia seu conteúdo completo.
2. Preserve somente as 3 a 5 tarefas mais recentes e pendências ainda ativas.
3. Destile regras recorrentes e estáveis para `SKILL.md` na camada Core ou específica do projeto.
4. Nunca altere a memória de Chefia sem instrução humana explícita.
5. Reescreva a memória de execução visando cerca de 5 KB e menos de 10 KB.
6. Confirme frontmatter das skills, caminhos de descoberta e diff Git recuperável.
7. Registre tamanhos e evidências no checklist do batch.
