# REQ-296 — Remoção de Payload Heurístico de Trojan no Teste de Upload e Blindagem Anti-Falso-Positivo

## 1. Contexto & Diagnóstico

Durante a execução da suíte de testes unitários do Core (`conn2flow`), o Microsoft Defender Antivirus no Windows 11 disparava repetidamente o bloqueio em tempo real com o alerta:
- **Ameaça:** `Trojan:PHP/Chopper.A!dha`
- **Status:** Removido
- **Alvo:** `C:\Users\otavi\AppData\Local\Temp\c2f-req240-<hash>\falso-anim.gif` (e similares: `.png`, `.jpg`, `.webp`, `.pdf`, `.glb`, `.svg`).

A investigação revelou que o arquivo `tests/Unit/PHP/ArquivoUploadReq240Test.php` (criado na REQ-240 para testar a validação de *magic bytes* de `arquivo_assinatura_confere()`) utilizava como fixture na linha 66 a string literal:
```php
$php = "<?php system(\$_GET['c']); ?>";
```
Essa linha grava 7 arquivos no disco com conteúdo idêntico à assinatura do webshell **China Chopper**, acionando a heurística de trojan em tempo real do Windows Defender sempre que os testes eram executados.

Como a função `arquivo_assinatura_confere()` valida estritamente a conformidade de cabeçalhos binários (*magic bytes* como `\x89PNG`, `\xFF\xD8\xFF`, `GIF89a`, `RIFF`, `%PDF-`, `glTF`, `<svg`), qualquer conteúdo que não contenha tais bytes mágicos comprova a rejeição com rigor idêntico, sem a necessidade de conter chamadas de execução shell de sistema (`system`, `exec`, `passthru`, `eval`).

## 2. Escopo de Implementação

1. **Higienização do Fixture de Teste**:
   - No arquivo `tests/Unit/PHP/ArquivoUploadReq240Test.php`, método `testConteudoQueContradizAExtensaoERecusado()`:
   - Substituir a string perigosa por um payload inofensivo que continue sendo um script PHP sem assinatura maliciosa e sem bytes mágicos de mídia, por exemplo:
     ```php
     $php = "<?php echo 'c2f-teste-conteudo-invalido-sem-magic-bytes'; ?>";
     ```
   - Garantir que todas as 7 asserções (`foto.png`, `foto.jpg`, `anim.gif`, `foto.webp`, `foto.pdf`, `modelo.glb`, `icone.svg`) continuem retornando `false` e sendo validadas com sucesso.
2. **Preservação de Contratos de Produção**:
   - A biblioteca de produção `gestor/bibliotecas/arquivo.php` **não deve ser alterada** (a lógica de verificação está 100% correta e segura).
3. **Validação de Não-Regressão**:
   - Executar `./vendor/bin/phpunit tests/Unit/PHP/ArquivoUploadReq240Test.php` e validar 8 testes e 46 asserções verdes (100% OK).
   - Garantir que nenhuma nova detecção seja disparada no Windows Defender durante a execução.
4. **Governança & Registro de Evidências**:
   - Criar `memory/implementation/BATCH-304.md` registrando as evidências da execução.
   - Atualizar a Live Todo List de `[ ]` para `[x]`.
