# req-295: conceitos, guias, CLI e API na 3.0.14

## Contexto

O `c2f docs:audit` de 2026-10-21 (core `bd8a609e`) aponta, por idioma, 14 docs em `concepts/`, 7 em `guides/`, 19 em `reference/cli/` e 8 em `reference/api/` com fontes alteradas desde `verified_at`. Seis docs ainda descrevem a governança como "SDD" e a pasta como `sdd/`, embora ela seja `memory/` (MDD) desde a REQ-266.

## Escopo

1. SDD para MDD (pt-br e en): `concepts/vision.md`, `guides/dev-tools-vscode.md`, `guides/documentation.md`, `reference/cli/ai.md`, `reference/cli/docs.md` e `reference/cli/help.md`. Conferir antes, no código, o que o CLI e a extensão aceitam hoje (`memory/` com fallback para `sdd/`).
2. Conceitos: `architecture`, `system-updates` (manifesto, choques, snapshot, volta automática, `dist/`), `css-and-tailwind` (cache portável), `admin-interface` (painel em Tailwind), `global-variables`, `hooks`, `multilingual`, `ai-security` e os demais.
3. Guias, CLI e API: comandos novos ou alterados da série 3.0 (`update:core`, `update:conflicts`, `update:resolve`, `update:rollback`, `project:deploy`, `--skip-css`, `memory:*`) e as rotas de CRUD da API (`/_api/{modulo}/`).
4. What's New 2.x: são notas históricas. Decidir com o humano se o `verified_at` delas deve ser fixado na tag da versão para saírem do ranking.
5. `docs:build` e publicação no Lab. Produção fica com o humano.

## Aceite

- Nenhum item de `concepts/`, `guides/`, `reference/cli/`, `reference/api/` ou `reference/hooks/` no `docs:audit`.
- Nenhuma menção a `sdd/` como pasta atual nas docs publicadas.

## Coordenação

As REQ-293 e REQ-294 tocam outras pastas de `ai-workspace/*/docs/`. O `docs:build` regera tudo: rodar a partir de árvore limpa e combinar a vez.
