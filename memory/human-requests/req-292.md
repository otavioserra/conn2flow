# req-292: Documentação online na 3.0 (frente 1)

## Contexto

Em produção, `https://conn2flow.com/docs/sdd/` ainda apresenta a governança como "SDD", embora a pasta seja `memory/` (MDD) desde a REQ-266, e `https://conn2flow.com/docs/whats-new/` termina na 2.10.13, com o core já em `gestor-v3.0.14`. O `docs:audit` aponta 258 itens com pendência (fontes alteradas desde `verified_at`).

## Decisões do humano (2026-10-21)

- A seção passa a `/docs/mdd/`, e os endereços antigos `/docs/sdd/...` respondem **301** para os novos.
- Esta REQ é a **frente 1**. A revisão geral das docs segue em REQs separadas, distribuídas pelo humano entre agentes.

## Escopo

1. `c2f docs:build`: a seção publicada a partir de `memory/` passa a se chamar `mdd` (URL, menu, `llms.txt`, ajuda do comando). A configuração `sdd` antiga continua aceita.
2. Sincronização de recursos (`sincronizarTabela`): quando uma página existente muda de `caminho`, o caminho antigo vai para `paginas_301`, como o painel já faz. Os ids das páginas da seção não mudam, então o 301 sai pelo roteador existente.
3. `conn2flow-site`: configuração e rótulos da documentação de SDD para MDD.
4. What's New da série 3.0 (3.0.0 a 3.0.14) em pt-br e en, a partir das tags e do CHANGELOG.
5. `docs:build` e publicação no Lab. Produção só com ok do humano.
6. REQs da revisão geral (bibliotecas, conceitos, módulos, guias) criadas como intake.

## Fora do escopo

- Reescrever as docs de referência apontadas pelo `docs:audit` (REQs seguintes).
- Deploy de produção sem ok explícito.
