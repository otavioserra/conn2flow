# req-278: Atualizador do core sempre entregue

## 1. Ocorrência (15/10/2026, 16:27, temp.conn2flow.com)

A linha de base do manifesto do core era a da tentativa pelo painel das 14:28 (3.0.3); depois o `temp` foi para a 3.0.4 por SSH, que não grava o manifesto do core. Entre os preservados estava o próprio atualizador com o hotfix da req-277: a etapa de banco rodou com o código antigo e estourou a memória de novo.
