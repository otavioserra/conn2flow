# req-157: Atualização das GitHub Actions para v4/v5 (Eliminação de avisos de depreciação do Node 20)

- **Status do intake**: ready-for-intake
- **Data**: 2026-09-02
- **Origem**: Alerta de depreciação no runner do GitHub Actions durante o release `gestor-v2.10.6`
- **Classificação**: DevOps, infraestrutura de CI/CD, sustentabilidade de workflows
- **Batch**: BATCH-160

---

## 1. O Sintoma e o Problema

Durante a execução da release `gestor-v2.10.6` no GitHub Actions (Job `release`), a plataforma emitiu o seguinte aviso formal de depreciação:

```text
Node.js 20 is deprecated. The following actions target Node.js 20 but are being forced to run on Node.js 24: 
actions/cache@v4, actions/checkout@v4, actions/setup-node@v4, softprops/action-gh-release@v2. 
For more information see: https://github.blog/changelog/2025-09-19-deprecation-of-node-20-on-github-actions-runners/
```

### Impactos Medidos:
- As actions oficiais da comunidade (`actions/checkout@v4`, `actions/setup-node@v4`, `actions/cache@v4`) ainda utilizam o runtime legado do Node 20 internamente, sendo executadas em modo de compatibilidade forçada no Node 24 pelos runners do GitHub.
- Atualizar as versões das Actions para as versões mais recentes que utilizam Node 24 garante execuções mais rápidas, sem warnings de depreciação e previne quebras futuras quando o GitHub encerrar o suporte ao Node 20.

---

## 2. A Solução Especificada

### 2.1 Atualizações no Workflow `.github/workflows/release-gestor.yml`
1. Atualizar `actions/checkout@v4` para `actions/checkout@v5` (ou última versão v4/v5 com runtime Node 24).
2. Atualizar `actions/setup-node@v4` para `actions/setup-node@v5`.
3. Atualizar `actions/cache@v4` para `actions/cache@v5`.
4. Atualizar `softprops/action-gh-release@v2` para a versão mais recente (`v2.2.1` ou `v2` com suporte atualizado a Node 24).

### 2.2 Atualizações no Workflow `.github/workflows/release-instalador.yml`
1. Atualizar `actions/checkout@v4` para `actions/checkout@v5`.
2. Atualizar `softprops/action-gh-release@v2` para a última versão.

---

## 3. Critérios de Aceite para o Agente Executor

- [ ] Todas as declarações `uses: actions/*` em `.github/workflows/release-gestor.yml` e `release-instalador.yml` atualizadas para as versões mais recentes suportadas pelo Node 24.
- [ ] Validação de sintaxe YAML (`npx --yes yaml-lint .github/workflows/*.yml` ou equivalente) realizada sem erros.
- [ ] Execução dos releases sem emissão de avisos de depreciação do Node 20.
