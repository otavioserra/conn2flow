## 1. Pedido, nas palavras do Engenheiro Chefe

> "No adicionar não tem modelos, e não é só nesse aqui não, eu vi em outros… No editar está. `https://conn2flow.local/forms/adicionar/` e `https://conn2flow.local/forms/editar/?id=e2e-req222-forms`… São duas formas de pegar modelo, tanto dessa forma [o seletor do módulo] quanto diretamente dentro do editor HTML, na aba modelos."

> "Dois modelos ele está cortando o layout… na verdade são três: contato básico, o checkout de assinatura e o checkout do comprador… o índice de produtos também, tanto a lista com a imagem quanto o destaque estão cortando a área útil… Na vertical cortar é normal. O problema é na horizontal."

## 2. Escopo

1. **Aba Modelos na inclusão**: nos módulos sem campo de framework CSS, a aba Modelos do editor lista os modelos do alvo também na tela de adicionar (e de clonar), antes de qualquer modelo ter sido carregado.
2. **Miniaturas**: nenhuma miniatura corta a área útil na horizontal, nem no arquivo nem no cartão em que o painel a mostra. Cortar na vertical é aceito.

## 3. Critérios de aceite

- [x] `forms/adicionar/`, `menus/adicionar/`, `publisher-index/adicionar/` e os demais módulos com editor listam os modelos na aba Modelos.
- [x] Escolher um modelo pela aba, na inclusão, aplica HTML e CSS e a prévia usa o framework do modelo.
- [x] Telas com campo de framework (páginas, layouts, componentes) continuam filtrando pelo framework escolhido.
- [x] Contato básico, os dois checkouts, e o índice de produtos (lista com imagem e destaque) aparecem inteiros na largura, no cartão do painel.
- [x] PHPUnit e Vitest verdes; conferência de navegador no Lab da 3.0.
