## 2. Por que agora ficou simples

O BATCH-144 criou `gestor/bibliotecas/editor-texto.php`, ponto único do Quill: versão do CDN, CSS do
editor, CSS de conteúdo publicado e paridade visual com a página. Um módulo passa a precisar apenas
de `editor_texto_incluir()` e da declaração `"editor-texto"` no manifesto.

## 3. Escopo

1. **Inicialização**: trocar os três `new tinymce.Editor(...)` por Quill, preservando o contrato do
   campo (valor lido/gravado como HTML) e o comportamento de múltiplos editores na mesma tela.
2. **Inclusão**: `configuracao.php` passa a chamar `editor_texto_incluir()`; remover o `<script>` do
   `cdn.tiny.cloud` e a API key.
3. **`html-editor-interface.js:861`**: substituir `tinymce.activeEditor.setContent()` pela API
   equivalente do Quill.
4. **Tipo de variável**: decidir entre manter o identificador `tinymce` por compatibilidade de dados
   ou migrar para um nome neutro (`richtext`), com migração dos registros existentes.
5. **Recursos**: atualizar o markup do `configuracao-campos` e os rótulos em `variables.json`
   (pt-br/en), com version bump.

## 4. Critérios de aceite

1. Nenhuma referência a `tiny.cloud` ou `tinymce` no core (exceto migração de dados, se houver).
2. Campo de variável do tipo rico edita e grava HTML idêntico ao comportamento anterior.
3. Múltiplos editores na mesma tela continuam funcionando de forma independente.
4. A inclusão passa exclusivamente pela biblioteca `editor-texto` — zero referência direta ao CDN.
5. Suítes PHPUnit e Vitest verdes; teste cobrindo a declaração da biblioteca no manifesto do módulo.

## 5. Observação

A API key do TinyMCE está versionada no repositório (`configuracao.php:464`). Ao remover a
dependência, convém revogá-la no painel do fornecedor — chave publicada em repositório continua
válida mesmo depois de o código sair.
