# Arquivo do Backlog

Mova para esta pasta itens promovidos, concluídos, rejeitados ou substituídos. Preserve o identificador original e atualize `../BACKLOG-INDEX.md` com o destino final ou a requisição promovida.

Arquivar não autoriza implementação; somente uma requisição ativa em `sdd/human-requests/` pode abrir trabalho de execução.
